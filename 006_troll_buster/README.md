# Классификация токсичных комментариев 


> ⚠️ **Внимание**
> 
> Проект содержит токсичный контент. А именно, ненормативную лексику и оскорбления, включая визуализацию Облако слов / Word Cloud, так как они отражают реальный состав исследуемого датасета. Данные материалы приводятся исключительно в научно-исследовательских целях.

Проект посвящен разработке инструмента модерации для интернет-магазина.<br> 
Цель исследования — построить модель машинного обучения, способную анализировать описания товаров и комментарии пользователей на английском языке, автоматически выявлять токсичные реплики и отправлять их на модерацию.

## Наблюдения и ключевые выводы

Проведено исследование частотности слов в обучающей выборке. Визуализация Облака слов наглядно показала основные маркеры токсичности, используемые пользователями. Для корректной подготовки признаков, исходные тексты комментариев были очищены от лишних символов с помощью регулярных выражений, приведены к нижнему регистру и лемматизированы с использованием инструментов библиотеки **NLTK**. Перевод текстов в числовые векторы выполнен методом расчета матрицы частоты слов **TF-IDF**.

В данных наблюдался сильный *дисбаланс классов* - токсичных комментариев значительно меньше нейтральных. При обучении моделей применялась балансировка весов классов `class_weight='balanced'`, были протестированы линейный классификатор и модель градиентного бустинга. Лучший результат показала модель **LGBMClassifier** с итоговым значением **F1 = 0.775** на тестовой выборке. Модель можно использовать для автоматической модерации магазина.
