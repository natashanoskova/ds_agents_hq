
# Исследование успешности игровых платформ и жанров

Проект посвящен анализу исторических данных до 2016 года о продажах компьютерных игр по всему миру из открытых источников.<br> 
Цель исследования — выявить определяющие успешность игры закономерности - влияние платформ, жанров, оценок критиков и возрастных рейтингов, чтобы помочь интернет-магазину выбрать потенциально популярный продукт и спланировать рекламные кампании на перспективу.

## Наблюдения и ключевые выводы

В ходе исследования определен характерный срок жизни игровых платформ. Это позволило выделить актуальный временной период для построения прогнозов. Анализ показал, что оценки критиков имеют заметно более сильное влияние на глобальные продажи игр, чем оценки рядовых пользователей. На основе распределений "ящик с усами" были определены потенциально прибыльные и лидирующие платформы на рынке, а также выявлены самые высокодоходные жанры.

Составлен *портрет геймеров* для каждого региона - **Северная Америка, Европа, Япония**. Выявлены кардинальные различия в игровых предпочтениях. На северо-американском и европейском рынках безоговорочно лидируют платформы домашней серии PlayStation / Xbox и экшен-жанры. Рынок же Японии уникален, там доминируют портативные консоли Nintendo и жанр Role-Playing, а влияние возрастного рейтинга ESRB минимально из-за специфики локальной системы сертификации. Проверка двусторонних статистических гипотез с помощью *t-теста Стьюдента* подтвердила равенство средних пользовательских рейтингов для платформ Xbox One и PC, а также выявила значимые различия в оценках жанров Action и Sports.
