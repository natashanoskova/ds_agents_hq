# Прогнозирование коэффициента восстановления золота из золотосодержащей руды

Проект посвящен разработке модели машинного обучения для промышленной компании.<br> 
Модель должна оптимизировать производство, предсказывая коэффициент восстановления золота из золотосодержащей руды на основе параметров технологического процесса флотации и очистки. Это позволит эффективно настраивать параметры оборудования, максимизировать выход драгоценного металла и минимизировать финансовые потери при запуске убыточных предприятий.

## Наблюдения и ключевые выводы

Проведена математическая проверка формулы эффективности обогащения. Расчетное значение на обучающей выборке совпало с признаком из датасета, MAE ≃ 0 (9.7e-15). Это подтвердило корректность предоставленных логов. Исследование технологического процесса показало, что суммарная концентрация всех веществ (золота, серебра, свинца) закономерно и значительно увеличивается от стадии к стадии: от исходной руды до финального концентрата. При этом доля серебра в процессе очистки падает, а доля свинца растет. Проверка размеров гранул сырья на обучающей и тестовой выборках показала идентичность их распределений, что гарантировало корректность последующего обучения моделей.

Для оценки качества алгоритмов была написана функция метрики **sMAPE**. Итоговая оценка формировалась как взвешенная сумма ошибок двух этапов производства: черновой флотации (25%) и финальной очистки (75%). В качестве лучшего решения была выбрана модель **Random Forest Regressor** с оптимизированными гиперпараметрами. На тестовой выборке модель показала значение итогового **sMAPE = 9.27**, опередив базовый константный прогноз и доказав свою экономическую эффективность для внедрения на производстве.
