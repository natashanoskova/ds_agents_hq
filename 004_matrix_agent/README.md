
# Защита персональных данных клиентов страховой компании

Проект посвящен разработке метода шифрования данных, который защищает конфиденциальную информацию клиентов страховой компании, не ухудшая при этом качество моделей машинного обучения.<br> 
Цель исследования — математически обосновать и реализовать алгоритм преобразования данных, после которого восстановить исходную информацию без ключа невозможно.

## Наблюдения и ключевые выводы

Разработан и математически доказан метод шифрования признаков, основанный на умножении матрицы исходных данных на случайную обратимую матрицу-ключ. Математическое доказательство подтвердило, что веса линейной регрессии на преобразованных данных выражаются через исходные веса и матрицу преобразования, что гарантирует способность модели предсказывать на том же уровне.

Для практической проверки разработанного алгоритма была обучена модель Линейной регрессии на исходных данных, и на зашифрованной матрице признаков. Метрика качества **R²** в обоих случаях совпала с точностью до десятого знака после запятой. Чтобы подтвердить идентичность работы моделей, проведен **статистический U-тест Манна-Уитни**. Тест подтвердил отсутствие статистически значимых различий между предсказаниями модели до и после шифрования, *p-value > 0.05*. Разработанный алгоритм решает задачу защиты персональной информации клиентов, сохраняя функциональность аналитических моделей компании.
