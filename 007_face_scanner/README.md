# Определение возраста покупателей по фотографии

Проект посвящен разработке системы компьютерного зрения для сетевого супермаркета.<br> 
Модель глубокого обучения предназначена для определения приблизительного возраста клиентов в прикассовой зоне, что позволит анализировать покупательскую способность различных возрастных групп и контролировать добросовестность кассиров при продаже алкоголя.

## Обзор исследования

| Задачи | Алгоритмы и Модели | Метрики | Стек |
| :--- | :--- | :--- | :--- |
| • Исследовательский анализ выборки изображений<br>• Аугментация и подготовка батчей данных<br>• Построение сверточной нейросети (CNN)<br>• Обучение на GPU-воркерах и оценка качества | • ResNet50 (предобученная на ImageNet)<br>• Adam optimizer<br>• GlobalAveragePooling2D | **Основная:**<br>MAE ⩽ 8 | Python, Pandas, NumPy, Plotly Express, TensorFlow, Keras |

## Наблюдения и ключевые выводы

В ходе исследовательского анализа данных было изучено распределение возраста на *7591 фотографии*. *Средний возраст* людей в выборке составил *около 31 года*, при этом на графике распределения отчетливо заметны локальные пики ("юбилейные" значения возраста), что указывает на возможное округление данных при разметке или специфику сбора датасета. Для повышения обобщающей способности модели при подготовке данных было настроено динамическое извлечение батчей с помощью `ImageDataGenerator` и нормализация пикселей.

Для решения задачи регрессии была выбрана глубокая сверточная нейросеть на архитектуре **ResNet50**, дообученная на целевом датасете. В качестве финального слоя использовался полносвязный слой с одним нейроном и линейной функцией активации. Модель успешно справилась с задачей, достигнув на тестовой выборке значения **MAE = 6.7** (лет), что удовлетворяет бизнес-требованиям супермаркета и позволяет определять возрастные группы клиентов.
