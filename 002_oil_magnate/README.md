# Выбор локации нефтяных скважин на основании прогноза прибыли и рисков

Проект посвящен определению наиболее прибыльного региона для бурения новых нефтяных скважин добывающей компании.<br> 
Цель исследования — построить модель машинного обучения, которая поможет минимизировать риски убытков и выбрать регион с максимальной суммарной прибылью на основе анализа характеристик проб нефти.

## Наблюдения и ключевые выводы

В ходе работы исследованы пробы нефти в трех различных регионах, по *100 000 скважин в каждом*. Рассчитан бюджет на разработку и минимальный объем сырья в скважине для безубыточного бурения, который составил 111.11 тыс. баррелей. Анализ показал, что средний запас скважин во всех регионах исходно ниже этой отметки, что доказало невозможность выбора локаций "вслепую" и подтвердило необходимость применения прогнозных моделей машинного обучения.

Для прогнозирования объемов сырья была обучена модель Линейной регрессии. С помощью техники **Bootstrap**, выполненной по 1000 выборкам, рассчитаны распределения потенциальной прибыли, доверительные интервалы и риски убытков для каждой локации. Единственным регионом, полностью удовлетворяющим условиям бизнеса, с рисками убытков менее 2.5%, стал **Регион №2**. Модель показала для него минимальную ошибку RMSE, метод Bootstrap подтвердил самую высокую среднюю прибыль и 95%-й доверительный интервал, находящийся в положительной зоне. Этот регион можно рекомендовать для разработки новых скважин.
