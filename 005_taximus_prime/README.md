# Прогнозирование количества заказов такси на следующий час

Проект посвящен разработке модели машинного обучения для сервиса такси.<br> 
Цель исследования — спрогнозировать количество заказов на следующий час на основе исторических данных о заказах такси в аэропортах. Это позволит компании своевременно привлекать большее количество водителей в периоды пиковых нагрузок и оптимизировать логистику.

## Наблюдения и ключевые выводы

Исходный ряд с периодичностью данных 10 минут за 6 месяцев ресемплирован по часовым интервалам. Анализ временного ряда показал выраженную внутрисуточную и внутринедельную сезонность, а также восходящий тренд общего количества заказов к концу летнего периода. Для построения прогноза созданы календарные признаки - день, час, день недели, а также добавлены отстающие значения, лаги, и скользящее среднее, улавливающее текущую динамику ряда.

При разделении данных сохранен хронологический порядок. Размер тестовой выборки составил 10%, а валидация моделей проводилась с помощью специализированного кросс-валидатора `TimeSeriesSplit`. Лучшее значение метрики качества **RMSE** было получено моделью **LGBMRegressor**.
