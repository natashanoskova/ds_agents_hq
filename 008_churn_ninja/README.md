# Прогнозирование оттока клиентов компании с целью повышения их лояльности

Проект посвящен разработке модели машинного обучения для оператора связи.<br> 
Цель исследования — вовремя находить клиентов, которые планируют уйти, чтобы компания могла удержать их с помощью специальных предложений и промокодов.

## Наблюдения и ключевые выводы

В ходе исследовательского анализа данных (EDA) была обнаружена *бизнес-закономерность*: чаще всего компанию покидают клиенты *с высокими ежемесячными расходами*, использующие подключение по оптоволоконному кабелю и *предпочитающие помесячную оплату*. Дополнительный анализ временных рядов (разложение притока и оттока на тренд и сезонность) показал, что у бизнеса есть выраженные "опасные" периоды в году, когда отток клиентов традиционно возрастает. Эти инсайты позволят маркетингу действовать превентивно, запуская промо-кампании именно в пиковые месяцы.

Победителем в исследовании стала модель **CatBoost Classifier**, показавшая на тестовой выборке отличный результат **AUC-ROC = 0.917** и **Accuracy = 0.91**, что превосходит показатели базовой Dummy-модели. Модель успешно находит 73% клиентов, действительно планирующих уйти, что делает её надежным инструментом для минимизации финансовых потерь компании и удержания лояльной аудитории.
